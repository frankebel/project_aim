\begin{abstract}
    We present an implementation of an Anderson impurity solver using a
    configuration interaction approach implemented inside the package
    \textsc{Fermions}.
    By combining a bit and vector representation we can improve the calculation
    of a power iteration for a given Hamiltonian and starting state by up to
    a factor of \num{2000} compared to the existing bit only representation.
    This will allow us to calculate systems with an impurity coupled to
    hundreds of bath sites in the future.
\end{abstract}
